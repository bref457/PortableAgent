# Security Policy

## Supported versions

PortableAgent is currently in development. Security fixes are applied only to
the latest revision of the default branch.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use the repository's **Security** tab to open a private security advisory. Add
only the information needed to reproduce and assess the issue, and never attach
real sensitive documents, credentials, model files, databases, or user data.

The maintainer will acknowledge the report as soon as practical, assess its
impact, and coordinate a fix before public disclosure.

## Security scope

Reports are especially helpful when they concern unintended network access,
unsafe file handling, prompt-injection boundaries, unvalidated model output,
source-file modification, persistent storage of document content, or leakage
of local paths and data.
