Nur auf diesem Gerät

Offline-first · Keine Telemetrie

Frage deine Dateien.
Die Belege bleiben sichtbar.

Dokumente und Tabellen werden lokal gelesen. Es gibt keine Cloud-Übertragung und keine automatische Dateisuche.

01

Dokument öffnen

Wähle eine lokale Datei aus und öffne sie direkt.

TXT, DOCX oder PDF · Die Datei bleibt auf diesem Gerät. Eine kurzlebige lokale Arbeitskopie wird nach dem Einlesen sofort entfernt.

02

Temporäre Sitzung

Wähle und verwalte lokal geöffnete Dokumente.

03

Belegte Frage

Nur gefundene Fundstellen gelangen an das lokale Modell.

04

Antwort & Quellen

Jede Antwort bleibt an die verwendeten Fundstellen gebunden.

⌁

Hier erscheint die lokal erzeugte Antwort.

Verwendete Fundstellen

    T1

    Tabelle befragen

    CSV, XLSX oder XLSM werden für genau diese Anfrage read-only geöffnet.

    Noch keine Tabelle ausgewählt

    Die Tabelle bleibt auf diesem Gerät. Bei Excel wählst Du einen Reiter; CSV benötigt keine Blattauswahl. Nur Spaltennamen und freigegebene Felddefinitionen gelangen an das lokale Modell.

    T2

    Ergebnis & Zeilenbelege

    Die Quelldatei bleibt unverändert und wird nicht in einer Sitzung gehalten.

    ∑

    Hier erscheint das lokal berechnete Ergebnis.
