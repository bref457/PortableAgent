# Synthetische Beispieldaten

Diese Dateien enthalten ausschliesslich erfundene Daten. Sie dienen dazu,
PortableAgent nach der lokalen Einrichtung ohne eigene Dokumente zu testen.

## Tabelle testen

1. PortableAgent mit `start.bat` starten.
2. In der Oberflaeche den Modus **Tabellen** waehlen.
3. `einsaetze.csv` ueber den Dateidialog auswaehlen.
4. Zum Beispiel fragen: `Wie viele Einsatzstunden gab es 2026?`

## Dokument testen

1. In der Oberflaeche den Modus **Dokumente** waehlen.
2. `projektinfo.txt` ueber den Dateidialog auswaehlen.
3. Zum Beispiel fragen: `Wann ist die synthetische Abgabe?`

Eigene Dateien werden auf dieselbe Weise ausgewaehlt. Sie muessen nicht in das
Projekt kopiert werden und werden nicht automatisch dauerhaft gespeichert.
