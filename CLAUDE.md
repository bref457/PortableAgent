# Claude Code

- `AGENTS.md` ist die gemeinsame, massgebliche Regelquelle fuer Codex, Claude
  Code und andere Coding Agents. Gemeinsame Regeln niemals nur hier
  duplizieren, sondern in `AGENTS.md` pflegen.
- Claude Code darf auf ausdruecklichen Wunsch des Benutzers als
  Entwicklungswerkzeug fuer dieses Repository verwendet werden. Das erlaubt
  weder Cloud-LLMs in PortableAgent noch Cloud-Fallbacks, Telemetrie oder das
  Hochladen beziehungsweise Lesen von Nutzdaten. Fuer Entwicklung und Tests
  ausschliesslich Repository-Code, technische Dokumentation und synthetische
  Daten verwenden.
- Nicht auf Chatverlauf oder Claude Auto Memory als einzige Quelle fuer
  Projektentscheidungen vertrauen. Dauerhafte Entscheidungen, Fortschritt,
  Grenzen und naechste Schritte in den von `AGENTS.md` genannten
  Projektdokumenten festhalten.
- Zu Beginn einer uebernommenen Arbeit `update dich` gemaess `AGENTS.md`
  ausfuehren. Vor einer dauerhaften Sicherung die dort definierte `save`-Regel
  anwenden.
- Mit `/context` kann geprueft werden, ob diese Datei und der Import von
  `AGENTS.md` geladen wurden.
